## Description

Slides the hash window when the sliding window fills up. This is a critical operation in LZ77 compression that maintains the hash chains while discarding old data.

## Algorithm

1. Calculate how much to slide based on current position
2. Move window contents using `rep movsd` and `rep movsb`
3. Update all hash chain pointers to reflect new positions
4. Update position counters (strstart, lookahead, etc.)
5. Recompute hash value for first 3 bytes at new position

## Key Operations

- **Block move**: Uses `rep movsd` for efficiency
- **Hash update**: Adjusts head[] and prev[] arrays
- **Position tracking**: Updates strstart, block_start, etc.

## C Code Equivalent

```c
void slide_hash_window(deflate_state *s)
{
    unsigned wsize = s->w_size;
    unsigned n = s->strstart - MAX_DIST;
    
    // Move window
    memmove(s->window, s->window + n, wsize);
    
    // Update position counters
    s->strstart -= n;
    s->block_start -= n;
    s->lookahead -= n;
    
    // Update hash chains
    for (int i = 0; i < HASH_SIZE; i++) {
        unsigned m = s->head[i];
        s->head[i] = (m >= n ? m - n : 0);
    }
    
    for (int i = 0; i < wsize; i++) {
        unsigned m = s->prev[i];
        s->prev[i] = (m >= n ? m - n : 0);
    }
    
    // Recompute hash
    s->ins_h = UPDATE_HASH(s->window[0], s->window[1], s->window[2]);
}
```
