## Code Analysis

### Parameters
- `[esp+0Ch]` (esi) = pointer to data buffer
- `[esp+0Ch]` (edi) = initial CRC/checksum value
- `[esp+18h]` (ebx) = data length

### Algorithm
This appears to be a CRC32 implementation:
1. Split initial value into high/low 16-bit parts
2. Process data in 16-byte blocks
3. Use lookup tables (likely in .rdata)
4. Combine results and return final CRC

### Return Value
- EAX = calculated CRC32 value, or
- EAX = 1 if input is NULL, or
- EAX = 0 if error
