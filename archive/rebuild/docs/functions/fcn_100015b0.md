## Description

Main deflate function that handles different flush modes and parameter processing. Implements the core compression loop state machine.

## Flush Modes Handled

- `Z_NO_FLUSH` (0): Continue compressing
- `Z_SYNC_FLUSH` (1): Sync flush
- `Z_PARTIAL_FLUSH` (2): Partial flush
- `Z_FULL_FLUSH` (3): Full flush
- `Z_FINISH` (4): Finish compression

2. Checks for valid flush mode (0-4)
3. Handles different compression states:
   - INIT_STATE (0x2a)

   - FINISHING_STATE (0x29a)
4. Calls appropriate compression handlers
5. Flushes output buffer when needed

## State Machine
