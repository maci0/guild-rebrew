## Description

Flushes the pending output buffer to the output stream. Copies pending data using fast block memory operations (rep movsd/rep movsb).

## Operation

1. Calculates amount to flush (minimum of pending and available output space)
2. Uses `rep movsd` for DWORD-aligned copy
3. Uses `rep movsb` for remaining bytes
4. Updates stream pointers and counts
5. Resets pending buffer when empty

## C Code Equivalent

```c
void flush_pending(z_streamp strm)
{
    deflate_state *s = strm->state;
    unsigned len = s->pending;
    
    if (len > strm->avail_out) len = strm->avail_out;
    if (len == 0) return;
    
    // Copy pending to output
    memcpy(strm->next_out, s->pending_out, len);
    
    // Update pointers
    s->pending_out += len;
    strm->next_out += len;
    strm->total_out += len;
    strm->avail_out -= len;
    s->pending -= len;
    
    // Reset if buffer empty
    if (s->pending == 0) {
        s->pending_out = s->pending_buf;
    }
}
```
