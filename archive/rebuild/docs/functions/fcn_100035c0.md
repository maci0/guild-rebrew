## What It Does (High Level)

Another global-flag gated helper (similar in shape to `fcn_10003520`), but with slightly different constant arguments.

- If the callback/global at `0x10034610` is NULL, it calls IAT `0x10024148` with constants and returns.
- If `0x10034618` is zero, returns.
- Loads a pointer argument into `esi` (`arg0` at `[esp+8]` after saving `esi`).
- If `(AL & 0x0D) != 0`, emits/formats via `0x1001a299` and calls `fcn_10002640` with `(0x117640e0, eax, 1)`.
- If `(AL & 0x02) != 0`, calls IAT `0x10024148` with `(0, arg0, 0x1002742c, 0x1030)`.
