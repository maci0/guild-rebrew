## What It Does (High Level)

Stream byte reader / refill helper operating on a state struct (`esi` = arg0).

- If `*(esi+0x3c) != 0`, returns `0xFFFFFFFF`.
- If `*(esi+0x4) == 0`, it attempts to allocate/refill by calling `0x1001A7E5` and `0x1001AA6A` and stores the result in `*(esi+0x4)`.
- On refill failure, sets `*(esi+0x3c)=1`, returns `0xFFFFFFFF`, and if `(*(esi+0x40)+0x0c) & 0x20` is set also writes `*(esi+0x38)=0xFFFFFFFF`.
- On success (or if bytes were already available), decrements `*(esi+0x4)`, reads a single byte from `*(esi)` and increments `*(esi)`.

## Notes

- Byte-identical assembly is stored in `rebuild/asm/_fcn_10003820.asm` and verified against `rebuild/asm/_fcn_10003820.bin`.
- Uses `org 0x10003820` so NASM reproduces the same `call rel32` displacements.
- Encoding quirks: MSVC6 used `33 C9` (`xor ecx,ecx`) and `8B C1` (`mov eax,ecx`), so the asm uses small `db` sequences for those exact bytes.
