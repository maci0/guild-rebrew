## What It Does (High Level)

Shutdown / reset helper.

- Iterates a small dword table at `0x10027078..0x10027084` and calls `fcn_10002640` for each entry, passing the current global config value at `0x10034618`.
- If `(BYTE)0x10034618 & 0x8` is set, calls an IAT function at `0x1002404c` and clears `0x11766204`.
- Zeros key globals/pointers:
  - `0x10034610`
  - `0x117660e0`
  - `0x10034618`
