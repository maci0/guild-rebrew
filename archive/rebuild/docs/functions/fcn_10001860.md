## Description

Helper function that writes 2 bytes to the pending output buffer. Used internally by deflate to queue output bytes before they're flushed.

## Parameters

- `deflate_state *s`: Pointer to deflate state
- `unsigned short val`: 16-bit value to write

## C Code Equivalent

```c
void put_short(deflate_state *s, unsigned short val)
{
    // Write high byte first
    s->pending_buf[s->pending++] = (unsigned char)(val >> 8);
    // Then low byte
    s->pending_buf[s->pending++] = (unsigned char)(val & 0xff);
}
```

## Structure Offsets

- `0x08`: pending_buf pointer
- `0x14`: pending count
