## What It Does (High Level)

This is a small helper that indexes into a table of variable-length entries.

- `arg0` points at a table header.
- `arg1` is an index.
- If `arg1 >= *(arg0 + 0x4)`, it returns `NULL`.
- Otherwise it returns a pointer to the `arg1`'th entry by walking forward using a per-entry length stored at the start of each entry.

This is called by `fcn_10002fc0` while selecting a block descriptor.

## Notes

- The bytes for this function are stored in `rebuild/asm/_fcn_10003140.bin` and the reconstructable assembly is in `rebuild/asm/_fcn_10003140.asm`.
- Encoding quirk: MSVC6 used `33 C0` for `xor eax,eax`; NASM defaults to `31 C0` for the same mnemonic, so the `.asm` uses a 2-byte `db` for that instruction to remain bit-identical.
