## Description

Finds the longest match in the hash chain starting from a given position. This is the core of LZ77 compression - finding repeated strings in the sliding window.

## Algorithm

1. Get current match position from hash chain
2. Compare bytes between current position and match position
3. Continue comparing while bytes match and within limits
4. Return length of longest match found

## Key Features

- **Early exit**: Stops if match exceeds nice_match threshold
- **Chain depth limit**: Uses max_chain_length to limit search
- **Byte-by-byte compare**: Unrolled comparison loop

## C Code Equivalent

```c
unsigned longest_match(deflate_state *s, unsigned cur_match)
{
    unsigned chain_length = s->max_chain_length;
    unsigned char *scan = s->window + s->strstart;
    unsigned char *match;
    unsigned best_len = s->prev_length;
    unsigned limit = s->strstart > MAX_DIST ? s->strstart - MAX_DIST : 0;
    
    do {
        match = s->window + cur_match;
        
        // Quick check first 2 bytes
        if (match[best_len] != scan[best_len] ||
            match[best_len-1] != scan[best_len-1] ||
            *match != *scan || match[1] != scan[1])
            continue;
            
        // Full byte-by-byte compare
        unsigned len = 2;
        while (len < MAX_MATCH && match[len] == scan[len])
            len++;
            
        if (len > best_len) {
            best_len = len;
            if (len >= s->nice_match)
                break;
        }
    } while ((cur_match = s->prev[cur_match & WMASK]) > limit &&
             --chain_length != 0);
             
    return best_len;
}
```
