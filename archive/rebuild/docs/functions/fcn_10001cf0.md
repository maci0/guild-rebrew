## Description

Reads input data from the application into the internal compression buffer. Handles the interface between the application's input stream and zlib's internal state.

## Parameters

- `z_streamp strm`: zlib stream
- `unsigned char *buf`: Buffer to read into
- `unsigned size`: Amount to read

## Operation

1. Determines amount to read (minimum of available input and requested size)
2. Updates CRC32 checksum if in gzip mode
3. Copies input data using block move operations
4. Updates stream pointers and counters

## C Code Equivalent

```c
unsigned read_buf(z_streamp strm, unsigned char *buf, unsigned size)
{
    unsigned len = strm->avail_in;
    
    if (len > size) len = size;
    if (len == 0) return 0;
    
    strm->avail_in -= len;
    
    // Update CRC
    if (strm->state->wrap == 1) {
        strm->adler = crc32(strm->adler, strm->next_in, len);
    }
    
    // Copy data
    memcpy(buf, strm->next_in, len);
    strm->next_in += len;
    strm->total_in += len;
    
    return len;
}
```
