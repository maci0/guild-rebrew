2. **setsockopt** (0x1001a17e): Sets socket options including buffer sizes
3. **bind** (0x1001a178): Binds socket to local address
4. **ioctlsocket** (0x1001a172): Sets socket to non-blocking mode
5. **socket** (0x1001a166): Creates a UDP socket (IPPROTO_UDP = 106)
6. **closesocket** (0x1001a160): Closes the socket
7. **Logging** (0x10003640): Logs initialization completion
