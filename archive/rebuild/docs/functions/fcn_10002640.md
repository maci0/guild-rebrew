## Description
Processes a flag byte and executes up to three independent actions:
- bit `0x1`: format/emit a message using string table entries and helper formatters
- bit `0x4`: call an indirect function pointer with the provided string and a fixed label
- bit `0x8`: compute string length, call an indirect callback, then emit a second fixed message

This looks like a message routing/telemetry/logging helper rather than compression logic.

## Key Control Flow
- Early branch on `flags & 1`
- Table scan over `0x10027078..0x10027084` for ID match
- Fallback formatter path if no table hit or formatter returns null
- Optional blocks for `flags & 4` and `flags & 8`

## External Calls
- `0x1001a299` and `0x1001a286`: formatting/build helpers
- `0x1001a207`: emit helper
- `0x1001a18a`: free/release helper
- indirect calls via pointers at `0x10024004` and `0x100240c0`

## C-like Pseudocode
```c
void fcn_10002640(char *msg, uint8_t flags, uint32_t id) {
    char *tmp = NULL;

    if (flags & 0x01) {
        int idx = find_id_in_table(id);   // table at 0x10027078..0x10027084
        if (idx >= 0) {
            tmp = format_with_template(idx);
        }
        if (!tmp) {
            tmp = format_fallback();
        }
        if (tmp) {
            emit(msg, tmp);
            emit("...fixed...", tmp);
            release(tmp);
        }
    }

    if (flags & 0x04) {
        callbackA(msg);
        callbackA("...fixed...");
    }

    if (flags & 0x08) {
        size_t n = strlen(msg);
        callbackB(global_ctx, msg, n, 0);
        callbackB(global_ctx, "...fixed...", 1, 0);
    }
}
```
