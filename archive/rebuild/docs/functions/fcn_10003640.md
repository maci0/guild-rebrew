## What It Does (High Level)

Global-flag gated emit/log routine.

- If `0x10034610` is NULL, calls IAT `0x10024148` with constants and returns.
- Loads a byte flag from `0x10034618`:
  - If `(flags & 0x01) == 0`, returns.
  - Otherwise, formats/emits a message using caller arguments `(arg0,arg1,arg2)`:
    - If `(flags & 0x20) != 0`, it first calls IAT `0x10024154` and includes that result in the formatted output.
    - Else it uses an alternate format string.
- After formatting, calls `fcn_10002640(0x117640e0, flags, arg3)` where `arg3` comes from `[esp+0x10]` after the pushes.
