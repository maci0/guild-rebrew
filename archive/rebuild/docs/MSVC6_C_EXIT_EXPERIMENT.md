# MSVC6 C Exit Rebuild Process

## Goal
Reproduce `Exit` (`VA 0x10009350`, 68 bytes) from pure C with MSVC6 and verify byte identity.

## 1) Extract original Exit bytes

```bash
dd if=original/Server/server.dll of=rebuild/experiments/msvc6_purec/slices/exit_original_68.bin bs=1 skip=$((0x9350)) count=68
```

## 3) Pure C implementation

- Source: `rebuild/c/exit.c`

Compile command:

```bash
wine tools/MSVC600/VC98/Bin/CL.EXE /nologo /c /O2 /MT /Gd \
  /Fo"rebuild/c/exit.obj" \
  /Fa"rebuild/c/exit.asm" \
  "rebuild/c/exit.c"
```

## 4) Extract and compare generated bytes

```bash
objcopy -O binary --only-section=.text rebuild/c/exit.obj rebuild/c/exit_text.bin
dd if=rebuild/c/exit_text.bin of=rebuild/c/exit_68.bin bs=1 count=68
cmp -s rebuild/c/exit_68.bin rebuild/experiments/msvc6_purec/slices/exit_original_68.bin
```

Result: exact match (`68/68` bytes).

## 5) Compiler option sweep (pure C)

Tested flags and byte diffs against original Exit(68):

- `0` diffs:
  - `/O2 /MT /Gd`
  - `/Ox /MT /Gd`
  - `/O2 /MT /Gz`
  - `/O2 /MT /Gd /Ob0`
  - `/O2 /MT /Gd /Ob1`
  - `/O2 /MT /Gd /Ob2`
  - `/O2 /MT /Gd /Oy`
  - `/O2 /MT /Gd /Oy-`
- non-exact:
  - `/O1 /MT /Gd` -> `33` diffs
  - `/Od /MT /Gd` -> `67` diffs

## 6) Rebuild full DLL with pure C Init + Exit

Compile exact-pure C functions:

- Init source: `rebuild/c/init.c`
- Exit source: `rebuild/c/exit.c`

Patch `.text` copy:

- Init at `.text` offset `0x8320` (48 bytes)
- Exit at `.text` offset `0x8350` (68 bytes)

Assemble full DLL with `rebuild/asm/server_pure_init_exit.asm`.

Verification:

- MD5: `43279c2f9e9fd4d7bbc3889fd02ea4ea`
- SHA256: `c7ac331f44292657c1fa613608ffd84c9d8ee778e3e7696c7782b37dd6d40ee5`

Result: bit-identical to `original/Server/server.dll`.
