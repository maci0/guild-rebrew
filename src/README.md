# Reconstruction sources

`Develop/` follows attested original paths where known. `Develop/Unassigned/`
contains bodies whose original unit remains unresolved. Target-specific address
bindings can share one C definition.

See [source layout](../docs/source-layout.md), [naming](../docs/naming_conventions.md)
and [project rules](../AGENTS.md) before moving or renaming a definition.
