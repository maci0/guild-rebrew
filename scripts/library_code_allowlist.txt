# VAs whose bytes come from a linked library but whose source is kept anyway.
#
# Only link-side reasons belong here. "We already reversed it" is not one:
# reversed library code is wasted work and should be deleted, not recorded.
# Each entry names the LIBCMT object being displaced and what goes wrong
# without it. See .scratch/libcmt_probe/SUMMARY.md for the byte evidence.
#
# Everything under crt_region/ is stock LIBCMT (68 of 68 measured). The files
# below are compiled only so the linker prefers them over the library object,
# because those objects drag in side effects the reference does not have.
