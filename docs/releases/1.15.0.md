# Guild Rebrew 1.15.0

2026-11-24 source reconstruction checkpoint. The validation records no gameplay or deployment tests.

Source and metadata only, no original game binaries or playable client build.

## Changes

- 35 commits since 1.14.0, 24 of them matching batches. 83 functions newly reach `EXACT` or `RELOC` (72 GoldTL, 11 Gold), compared against the 1.14.0 `rebrew-functions.toml`. New `EXACT` rows: GoldTL `fcn_004321a0`, `fcn_004f14c0`, `fcn_005e6df0`; Gold `fcn_004321a0` (0x4324e0) and `fcn_00493a30`. [The provenance ledger](../provenance.md) has each batch's before/after counts.
- 27 GoldTL rows that were `EXACT` or `RELOC` in 1.14.0 now carry no match status. All are library functions: library code is no longer reconstructed (commit 4fc439880), so their sources were deleted and the rows adopted into `src/library_d3dx8.h` (8) and `src/library_libcmt.h` (2), bound to vendored zlib, or retired (17). No game function fell below `RELOC`.
- Library coverage: LIBCMT objects placed with corrected extents and 287 CRT rows adopted; D3DX8 placed and its reconstructed copies dropped; the WS2_32 ordinal thunks named.
- Names and types: 730 functions named from reviewed evidence, 26 types renamed to `UPPER_CASE`, and shared struct headers for the entity, building, object and GUI tables.
- Matching rounds by several lane models, each batch gated on both client links, the byte-identical server link, all-target lint and no stored status falling. Keeps that lowered a stored status were held back.
- Documentation review: setup consolidated in the build guides, README, docs index, work queue and status graphics refreshed, research and SDK receipt locations corrected.
- Pinned rebrew 6.74.0 (was 6.60.0). Project and lockfile version 1.14.0 to 1.15.0.
