- 16 commits since 1.11.0. 140 functions newly reach `EXACT` or `RELOC` (52 GoldTL, 88 Gold) and none regress, compared against the 1.11.0 `rebrew-functions.toml`. New `EXACT` rows: GoldTL `fcn_004cefb0`, `fcn_005efd86`, `fcn_0064d1df`; Gold `fcn_00453ed0`, `fcn_00454030`, `fcn_00458a10`, `fcn_004f39b0`, `fcn_004f97a0`, `fcn_0052e1c0`, `fcn_0053f100`, `find_zone_record`. [The provenance ledger](../provenance.md) has each before/after count.

- Native-evidenced behavior fixes: building and object table loads bound to `lpGebaeudePROT` and `lpObjektePROT` where the code reads 0x868050 and 0x99ec10, `gm_RandomMod` declarations aligned with `zufall.c`, message-loop identity helpers called with the function's own symbol, and the Gold message loop calling its native helper `fcn_005309d0`.
- Gold function extents repaired from native padding evidence; zlib `0x465160` is now 1,064 bytes and `RELOC`.
- Documentation reconciled for setup, verification and archived research; the BSS and data-lead generators retired.
- Pinned rebrew 6.33.0. Project and lockfile version 1.11.0 to 1.12.0.
