# Guild Rebrew 1.14.0

Source and metadata checkpoint, 2026-11-19. The release ships no game binaries
or a playable client build. The validation records no gameplay or deployment tests.

## Changes

- 62 commits since 1.13.0. 69 functions newly reach `EXACT` or `RELOC` (39 GoldTL, 30 Gold), compared against the 1.13.0 `rebrew-functions.toml`. New `EXACT` rows: GoldTL and Gold `ch_RemoveQueueEntry`, Gold `fcn_0041e740`, `fcn_0044a9e0`, `fcn_0045cdf0`, `fcn_00454500`, `fcn_004ef760`, `fcn_004115b0`. [The provenance ledger](../provenance.md) has each before/after count.
- 27 rows fall below `RELOC` (20 GoldTL, 7 Gold), among them GoldTL 0x4321a0 and Gold 0x4324e0 from `EXACT`. Steering `volatile` casts were removed; the timer-thread clock and its neighbours are now declared `volatile` where they are defined, as the native timer callback requires. That recovered 45 of the 83 rows the removal dropped; these 27 stay below until a faithful form is found.
- Shared declarations: `game/game_data.h` declares 242 client globals that every user typed the same way (client builds only), and 981 client sources use it in place of local `extern` lines. Files whose local types conflict keep their declarations. Server translation units keep theirs, because moving them changed server code.
- 23 `*_gconf.h` headers removed. They held minority-type externs moved out of their sources so the data conflict check no longer saw them; the uses now name the access width explicitly. A `.text` address used as data is now the callback function it is.
- Shared structs: 24 headers beside their units replace per-file typedef views of one global (market segments, windows, event records and others), each field settled from native accesses.
- Names: 120 globals renamed from address labels to evidenced module-prefixed names (103 client, 17 server), each proposed by one review lane and confirmed by a second; rows in [the name ledger](../name-ledger.tsv). Placeholder locals renamed in 681 sources with bytes unchanged. `d3snd_` joins the prefix table on its native strings.
- Compiler constants referenced as externs are written as literals where the measured bytes hold.
- Pinned rebrew 6.60.0 (replicated metadata state format 2). Project and lockfile version 1.13.0 to 1.14.0.
