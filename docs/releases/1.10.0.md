# Guild Rebrew 1.10.0

2026-11-05 source reconstruction checkpoint.

This release consolidates the reviewed GoldTL working tree, shuts down the completed parallel research sessions and removes local experimental/build clutter. It includes source and metadata, not original game binaries or a playable client build.

## Changes

- Retain native-evidenced corrections across 123 C translation units, including record strides, byte/field selection, pointer reaching definitions, boolean arguments, loop state, read sizes and return paths.
- Preserve accepted metadata and the append-only provenance ledger. Compilation verdicts remain separate from semantic claims; existing SIZE_MISMATCH and unresolved binding/state questions are not promoted by this release.
- Consolidate unfinished findings and rejected proposals in [the reconstruction handoff](../FLEET-HANDOFF.md). Unaccepted scratch candidates are excluded from production source and release assets.
- Put 0055f590 before 0055f5c0 in their shared source to match native function order, and wrap an overlong debug-format call without changing its arguments.
- Bump the project and lockfile version from 1.9.0 to 1.10.0 while preserving dependency pins.

## Repository cleanup

Only `main` and its current worktree existed after fetching; there were no other local or remote branches to merge. All remaining historical subagents were archived, and the supervision heartbeat was removed.

Historical scratch evidence, backups and local research state are retained outside the project in `../guild-rebrew-archive/2026-11-05/`. Disposable compile caches, build trees, response directories and test caches were cleared after validation. Reference inputs and canonical inventories remain in place. The external research archive is local-only and is not a release asset.

## Validation

- Project Python tests: 39 passed, with 3 subtests passed.
- Fresh server build: zero compile/link errors; 316/316 function checks and 652/652 data checks passed. File, sections, exports, imports, relocations, resources, headers and layout all match. Wine load/exports passed.
- Raw server image: 286,720 bytes, identical to the reference; SHA-256 `3cc2ce9049e41ab6d0eea042df4966fbf57e5e27c67fb923e81709d2683609d1`.
- Strict gate: **FAIL**, due to five lint warnings and 28 GoldTL D3DX library-screening findings. The five warnings concern three missing STUB blocker explanations, stale type evidence for `amt.office_slot:SERVER`, and generated instruction drift. No unreviewed metadata/type change was used to suppress them.
- Dependency lock validation and Git whitespace/conflict checks passed.

- Changed-source verification: all 123 C translation units compiled across their bound targets, with no build or extraction errors. The 126 function verdicts were 5 RELOC, 1 NEAR_MATCHING, 118 SIZE_MISMATCH and 2 STUB. These are measurements, not new promotions or whole-body semantic proofs.
- One initial check timed out waiting for the shared compiler lock; its later run completed. The translation unit whose function order changed was rechecked after that edit.

Changed-source checks used canonical whole-TU flags and `--no-promote`; byte mismatches were retained as mismatches. The server gate refreshed its managed function/data verification through the CLI.

This is a source checkpoint, not a claim of complete client byte identity, successful gameplay testing, or production readiness.

No production deployment applies: this repository has no configured production service or deployment workflow. Release publication supplies a source archive and SHA256SUMS, matching the previous release format.
