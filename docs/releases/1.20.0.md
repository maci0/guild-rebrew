# Guild Rebrew 1.20.0

2026-11-28 source reconstruction checkpoint. The validation records no gameplay or deployment tests.

Source and metadata only, no original game binaries or playable client build.

## Changes

- Function names: naming batches n11 to n16 named most remaining functions from evidence in the code. Function rows with source that still carry a generated `fcn_` name fell from 1,814 to 188 (GoldTL 151 of 5,152, Gold 37 of 2,377); every server function is named. Of the 5,430 renames in `docs/name-ledger.tsv`, 845 are attested by strings, script tables, diagnostics or twin symbols and 4,585 are inferred from verified bodies or uses.
- Globals: batch n16 named client data rows from their uses (`<module>_CamelCase` and the attested forms in `docs/naming_conventions.md`). Data rows still carrying an address label fell to 69 of 380 (Gold) and 12 of 274 (GoldTL).
- Source files: 4,223 single-function files are named after their function; 180 more dropped their `GOLD.`/`GOLDTL.` prefix. 107 Gold/GoldTL twin pairs are one file each (13 as one definition both clients build, the rest with edition guards). `Units/vfs/vfs.c` is the single source of its functions for all three targets.
- Placement: files in `src/Develop/Unassigned/` fell from 2,719 to 196, moved into the directory of their unit or subsystem; the rule and its basis are in `docs/source-layout.md`, "Subsystem directories", and every move with its evidence in `docs/placement/moves.tsv`.
- Headers: 165 to 134. Unused and single-user extern headers were removed or inlined, the rest moved next to their users or their owning subsystem, with root-relative `Develop/...` includes; the `src/` root keeps 16: the 14 `library_*.h` metadata headers, `layout_spans.h` and `client_video_list.h`, whose only users are still in `Unassigned/`.
- Rebrew pinned at 6.93.0 (was 6.84.0). Releases 6.85.0 to 6.93.0 carry fixes found here, including batch renames, a 50 times faster `source rehome`, and K&R definitions in `library bind-source`.

## Validation

- Full gate on the committed tree with rebrew 6.93.0: both clients link (with naming placeholders for names no client body defines yet); `scripts/gate.sh` passes with the server raw link identical to the reference; `rebrew lint` reports 5,166 files passed and zero findings on each of the three targets.
- `uv run --frozen pytest -q tests`: 50 passed, 9 subtests passed.
- Raw server image: 286,720 bytes, identical to the reference; SHA-256 `3cc2ce9049e41ab6d0eea042df4966fbf57e5e27c67fb923e81709d2683609d1`.

This is a source checkpoint, not a claim of client byte identity, gameplay testing or production readiness.
